# 5. Expected Judge Questions

### Why is AI required?

Answer:

AI reduces manual analysis by combining multiple environmental indicators into a single explainable priority score.

---

### Why not use existing dashboards?

Answer:

Most existing tools focus on a single dataset.

Ocean Sentinel OS integrates reef health, ghost nets, weather, protected areas, missions, and AI recommendations into one workflow.

---

### Is the AI replacing officers?

Answer:

No.

The AI only provides recommendations.

Final decisions remain with authorized officers.

---

### How does the AI calculate risk?

Answer:

The AI evaluates multiple environmental indicators using a transparent rule-based scoring engine.

Every recommendation includes a human-readable explanation.

---

### Can this scale?

Answer:

Yes.

The architecture supports future integration with PostgreSQL, satellite imagery, IoT devices, machine learning models, and cloud deployments.
